# Amazon Clone 🛒

A front-end clone of the Amazon e-commerce homepage, built using pure **HTML** and **CSS**. This project replicates the core UI layout and visual design of Amazon's website as a front-end development practice exercise.

---

## Features

- **Responsive Navbar** — includes the Amazon logo, delivery location indicator, search bar with category selector, account/sign-in section, returns & orders, and cart icon.
- **Navigation Panel** — secondary nav bar with department links (Today's Deals, Customer Service, Registry, Gift Cards, Sell) and a highlighted deals section
- **Hero Section** — full-width banner image with an inline redirect message linking to Amazon India
- **Product Grid** — 8-category shopping section with image cards covering Health & Personal Care, Games & Accessories, Jeans, T-Shirts, Women Tops, Women Boots, Kitchen Appliances, and Crocs
- **Full Footer** — multi-column footer with "Back to Top", informational link columns (Get to Know Us, Make Money with Us, Amazon Payment Products, Let Us Help You), logo panel, and copyright bar

---

## Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Page structure and semantic markup |
| CSS3 | Styling, flexbox layout, hover effects |
| Font Awesome 7 | Icons (location pin, search, cart) |
